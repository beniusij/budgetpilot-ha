# Changelog

## [0.3.45] — 2026-08-30

### Changed — 2026-08-29

- **Small wording and tidying on the Settings page.** The date in the header now reads "Household created" rather than "Household established", and in ordinary sentence case instead of capitals. The "Budget categories · <month>" line above the categories table has gone: the tab already says Categories, and the list is not limited to that month, so the line was saying something that was not true of what sat beneath it. **Add category** has moved onto the same row as the search box and the scope filter, so the controls for the list sit together instead of on two rows.
