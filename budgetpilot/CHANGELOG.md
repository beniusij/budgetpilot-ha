# Changelog

## [0.4.32] — 2026-10-06

### Added

- **The Home Assistant add-on's log now shows what each paired machine is doing.** Every sync writes a line naming the machine and how many changes it took or sent. Every check for a Mac update, and every download of one, writes a line too. You can now see from the box that a machine is still syncing, and which version it is fetching.
