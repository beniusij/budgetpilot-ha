# Changelog

## [0.3.43] — 2026-08-29

### Added — 2026-08-29

- **The little ⓘ explanations now open on a tap.** On a phone or tablet there is no cursor to hover, so the explanations behind the ⓘ marks — and the amounts behind the Needs / Wants / Savings rows and gauges — had no way of being opened at all. Tapping one now shows it, tapping it again puts it away, and tapping anywhere else dismisses it. Nothing changes if you are using a mouse.
